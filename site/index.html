How code reading works

How the code reader works

  1. 01

    Selection or current line

    Select the exact code you need. With no selection, the reader uses the cursor’s line.

    Alt + Shift + S
  2. 02

    Hear symbols and indentation

    Braces, operators, indentation, camel case, and snake case become explicit spoken labels.

    !== → strictly not equals
  3. 03

    Follow and repeat

    Move through a file hands-free or replay the last code without losing your position.

    Alt + Shift + F / R
  4. 04

    Set pronunciations for project words

    Teach project names and abbreviations once. Export the map, then import it in the other extension.

    kubectl → cube control

Privacy

Code stays on your device

The reader does not send code to a Code Listen Cursor service. It speaks only through voices your browser marks as local.

Installation note

Install the extension

  1. Download and unzip the extension.
  2. Open chrome://extensions or edge://extensions.
  3. Enable developer mode, choose “Load unpacked,” and select the unzipped folder.
