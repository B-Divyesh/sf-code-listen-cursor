Anatomy of a listening cursor

Control at the scale of a line

  1. 01

    Selection or current line

    Select the exact code you need. With no selection, the cursor’s line is the specimen.

    Alt + Shift + S
  2. 02

    Structure-aware speech

    Braces, operators, indentation, camel case, and snake case become language you can distinguish.

    !== → strictly not equals
  3. 03

    Follow and repeat

    Move through a file hands-free or replay the last observation without losing your position.

    Alt + Shift + F / R
  4. 04

    Your own vocabulary

    Teach project names and abbreviations once. The pronunciation map stays in extension storage.

    kubectl → cube control

Privacy

Your source stays on this device.

The reader does not send code to a Code Listen Cursor service. It asks the browser to speak and prefers voices marked local.

Installation note

Install the extension

  1. Download and unzip the extension.
  2. Open chrome://extensions or edge://extensions.
  3. Enable developer mode, choose “Load unpacked,” and select the unzipped folder.
