Plain-language policy · effective August 29, 2026

Privacy

Code Listen Cursor reads code in your browser or editor. It has no account or code-upload step.

Demo

The demo stores pronunciation entries under a separate demo key. Reset demo removes that key.

Automated privacy checks confirm that editing and listening send requests only to this site.

Installed browser extension

The browser extension saves only reading settings in extension-local storage. Its installed-package test confirms that listening makes no remote request and source code is not stored.

Speech

The reader speaks only through a voice your browser or editor marks as local. Your browser and operating system control installed voices.

If no local voice is available, speech stays off and the spoken preview remains visible. Source is never passed to a non-local speech voice.

VS Code extension

The VS Code extension saves only reading settings in local extension state. Its packaged integration test confirms that source code is not saved or sent over the network.

Remove settings

Remove pronunciations in reading settings, clear stored extension data, or uninstall the extension. Reset demo removes its sample setting.

Contact

Open questions or security reports in the public GitHub issue tracker. Do not include private source code.
