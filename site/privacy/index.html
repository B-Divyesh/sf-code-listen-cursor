Plain-language policy · effective August 28, 2026

Privacy

Code Listen Cursor is built so it does not need to know what you are reading.

What stays on your device

Selected code, current-line text, your pronunciation map, voice choice, reading rate, indentation preference, and follow state are handled locally. Preferences are stored with the browser extension’s local storage.

Speech

The extension uses your browser’s Web Speech interface and prefers a voice that the browser marks as local. Your browser or operating system controls the installed voices. If you deliberately select a network voice supplied by your system, that provider’s terms may apply; Code Listen Cursor does not choose or contact that provider itself.

What we collect

Nothing. This site and extension contain no analytics, advertising, tracking pixels, cookies, account system, or crash reporting. The hosting service may retain standard security logs such as an IP address and request time.

Permissions

Access to pages lets the extension read a selection only when you invoke listening or cursor follow. Storage saves preferences. The context-menu permission adds “Listen to selected code.” The extension does not upload page content.

Removing data

Remove pronunciation entries in the extension popup, or uninstall the extension to remove all locally stored preferences.

Contact

Questions or security reports can be opened in the public issue tracker. Do not include private source code in a report.
