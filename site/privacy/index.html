Plain-language policy · effective August 29, 2026

Privacy

Code Listen Cursor reads code in your browser or editor. It has no account or code-upload step.

Demo

The sample-code demo keeps its pronunciation entry in a separate demo browser-storage key. Reset demo removes that entry. The demo network test records only requests to this site while you edit and listen.

Installed browser extension

The browser package saves its reading settings, including a pronunciation entry, in browser extension local storage. Its package test records no remote request while it listens to selected code.

Speech

The reader asks the browser to speak and prefers a voice that the browser marks as local. Your browser and operating system provide and control installed voices. A network voice you deliberately choose is governed by that voice provider.

VS Code adapter

The VS Code package provides its own reading settings and personal pronunciation panel. It uses VS Code extension state for those settings.

Remove settings

Remove a pronunciation from the reader settings, clear the extension’s stored data, or uninstall the extension. The demo’s Reset demo button removes its sample setting.

Contact

Questions or security reports can be opened in the public issue tracker. Do not include private source code in a report.
